# PRCS Health Capacity

نظام إدارة وتحليل القدرة التشغيلية لقطاع الصحة في جمعية الهلال الأحمر الفلسطيني.

## الوظائف الرئيسية

- إدارة المراكز والمنشآت والإدارات الرئيسية والأقسام.
- قائمة موحدة للمسميات الوظيفية.
- تسجيل الاحتياج والموجود واحتساب العجز تلقائيًا.
- لوحة عرض بالفلاتر وتصدير المؤشرات بصيغة PDF.
- تسجيل دخول عبر ChatGPT وإدارة المستخدمين والصلاحيات.
- قاعدة بيانات D1 مع بيانات الأساس المستوردة من الملف الأصلي.
